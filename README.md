# company-ranking-app
# Corporate Data Multi-Metrics Analyzer

EDINETや厚生労働省（しょくばらぼ・女性活躍推進データベース）の公開データを統合し、任意の指標（財務、労働環境、多様性など）に基づいて企業データを多角的に分析・可視化するStreamlitダッシュボードです。

## 開発の背景と目的
膨大な企業の公開データから、特定の条件や価値観（例：ワークライフバランス、成長性、報酬水準）に合致する企業を客観的かつ効率的に抽出するため、独自のスコアリングアルゴリズムを用いた分析ツールを開発しました。

## 主な機能
- **動的スコアリング:** ユーザーが設定した各指標の重み（Weight）に基づき、リアルタイムで総合スコアを再計算。
- **統計的正規化:** 各指標のスケールの違いを吸収するため、Zスコアおよび誤差関数（math.erf）を用いたパーセンタイル変換を実施。
- **データクレンジングと欠損値補完:** 表記ゆれ（万円、億など）の正規化や、年齢による給与水準の線形回帰（`np.polyfit`）補正処理。
- **URLステート管理:** 分析パラメータ（重み設定やフィルタ条件）をBase64化してURLに埋め込み、分析状態の保存・共有を実現。
